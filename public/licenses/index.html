Hongdown 포매터

문서 정리는 Hong Minhee 및 기여자의 @hongdown/wasm@0.5.3을 포함하며 GPL-3.0-or-later로 배포합니다. 원본 소스는 Git 태그 0.5.3의 커밋 884fd93f8c766c16a2861868fa3b8b296309f5aa입니다.

  • Hongdown GPL-3.0 전문
  • Hongdown 0.5.3 대응 소스
  • Hongdown 원본 릴리스

Hongdown 재빌드 방법은 소스 압축 파일의 .github/workflows/main.yaml에서 build-wasm 작업을 참고하세요. Rust wasm32-unknown-unknown 및 wasm-pack으로 wasm-pack build --target web --features wasm을 실행하고, 생성된 pkg/*를 packages/wasm/pkg/에 복사한 뒤 그 폴더에서 pnpm install --no-frozen-lockfile과 pnpm run build를 실행합니다.

이전 Granite 버전의 MIT 라이선스 고지를 보존합니다. 다른 라이브러리의 저작권과 라이선스는 각 패키지에 남아 있습니다.
