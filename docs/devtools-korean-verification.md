# Chrome DevTools 한글 검증 — 2026-10-24

대상: `http://127.0.0.1:4173/`, Chrome 156.0.0.0, 별도 `granite-native-validation` 브라우저 컨텍스트. 기존 사용자 노트와 Chrome 개인 탭은 수정하지 않았다.

## 직접 수행한 페이지 검증

DevTools의 클릭·텍스트 입력·키보드 명령으로 수행하고, 화면과 데모 저장 원문을 대조했다. 텍스트 입력은 완성 문자열 삽입이며 macOS IME 자모 조합을 재현했다고 주장하지 않는다.

- `한글 검증 / 생각과 기록 🪨` 제목 생성. 인코딩된 단일 `.md` 키와 원래 제목 보존 확인.
- `오늘 읽은 글을 내 말로 정리합니다.`, `값, 읽다, 앉다, 꽃.`, 호환 자모 `ㄱ ㅏ`, 분리 자모 `한`, 이모지 `🪨` 입력·저장 확인.
- 마지막 문장을 선택해 `수정 후에도 한글이 보존됩니다.`로 교체. 실행 취소로 원문 복귀, 다시 실행으로 수정문 복귀 확인.
- `[[좋은` → Enter로 `[[좋은 질문을 모으는 일]]` 삽입.
- `@오늘` → Enter로 실행 당시 로컬 날짜 `[[2026-10-24]]` 삽입.
- `@산책` → Enter로 `[[산책과 생각의 속도]]` 삽입. 원문 보기와 저장 원문에서 모두 일반 위키링크임을 확인.
- `받침 확인` 본문 검색으로 검증 노트 한 개가 검색됨.
- 첫 문장을 키보드로 선택해 `내 말로 정리한 생각`으로 옮김. 원래 위치에 링크, 대상에 정확한 한글 문장, 백링크를 확인.
- 대상에서 `옮긴 뒤에도 이어서 다듬었습니다.`를 추가하고 새로고침 후 다시 열어 정확한 본문 보존 확인.

## 발견한 문제

새로 만들거나 옮긴 노트에서 새로고침하면 저장된 본문은 남지만 마지막 편집 노트 대신 샘플 노트가 열렸다. 수정 에이전트가 생성·옮기기 경로의 마지막 노트 기억 누락을 확인하고 현재 노트 변경 시 공통으로 기억하도록 수정했다. S02에 이어쓰기 동작을 명시하고 회귀 테스트를 추가했다. 독립 검토에서도 차단할 문제는 발견되지 않았다.

수정 후 DevTools로 직접 재검증했다.

- `한글 이어쓰기 수정 검증`을 새로 만들어 두 줄 한글을 저장하고 새로고침 → 같은 제목과 정확한 본문 유지.
- 첫 문장을 `옮긴 한글 노트 재접속 검증`으로 옮기고 새로고침 → 새 대상이 다시 열리고 정확한 선택 문장 유지. 원본에는 링크와 남은 한글·이모지 보존.
- 화면의 제목·본문·저장 완료 표시와 저장 원문을 함께 확인했다.

회귀 테스트는 수정 전 생성·옮기기 두 경로에서 실패했고, 수정 후 통과했다. 전체 검증은 단위 38개, 브라우저·디스크 28개 통과 및 타입 검사·프로덕션 빌드 성공으로 마무리했다. 기존 번들 크기 안내는 남아 있다.

콘솔의 404는 `/favicon.ico` 요청으로 확인했다. 본문 편집 예외나 저장 실패는 관찰하지 않았다. 파비콘 누락은 글쓰기 검증과 별개의 경미한 외관 항목이다.

## 실제 브라우저 파일 핸들 검증

DevTools에서 운영 `DirectoryStorage`와 Chrome의 실제 `FileSystemDirectoryHandle`을 연결했다. 임시 디렉터리는 **OPFS(사이트 전용 비공개 저장소)**에 만들었다. `showDirectoryPicker()`를 대체하거나 승인한 것은 아니며, Finder의 사용자 폴더 접근 검증과 구분한다.

- 한글·특수문자·이모지 제목 생성과 본문 편집 후 `createWritable()`/`close()`를 거친 실제 파일 원문 확인.
- 아주 긴 한글 제목을 해시 파일명으로 저장하고 원래 제목 왕복 확인.
- 별도 파일 스트림으로 외부 변경을 넣은 뒤, 오래된 기준본 저장이 충돌로 거부되고 외부 내용이 보존되는지 확인.
- 페이지 새로고침 후 같은 OPFS 디렉터리를 다시 열어 두 파일의 제목·한글 본문이 정확히 보존됨을 확인.

## 사용자 직접 조작이 필요한 부분

폐기 가능한 표본 폴더를 준비했다: `/private/tmp/granite-manual-20261024-7u2ixnip/A/노트`와 `/private/tmp/granite-manual-20261024-7u2ixnip/B/노트`. 두 폴더는 같은 이름이며 서로 다른 `기존.md`, 변경하면 안 되는 `보존.txt`, 목록에 나오면 안 되는 `하위/숨은.md`가 있다.

1. **실제 폴더 권한:** 데스크톱 Chrome에서 ‘내 폴더 열기’로 A를 선택·승인한다. 한글 노트를 쓰고 Finder에서 실제 `.md` 저장을 확인한다. 새로고침·재연결과 선택 취소/권한 거부도 확인한다. B로 전환할 때 A의 초안이 섞이지 않아야 한다.
2. **실제 한글 IME:** 두벌식 입력으로 `읽었습니다`, `값`, `앉다`를 천천히 조합하고 Backspace로 받침을 지운 뒤 다시 입력한다. `[[`와 `@` 메뉴 안에서도 한글을 조합하며 Enter가 조합 확정과 메뉴 선택을 부당하게 함께 실행하지 않는지 확인한다.

위 두 항목은 DevTools 문자열 입력이나 OPFS 통과 결과로 대신 검증했다고 보고하지 않는다.
