# 한국어 가로쓰기와 시작선 정렬

2026-10-25. [W3C 한국어 조판 요구사항](https://www.w3.org/TR/klreq/)을 참고한 제한적인 가로쓰기 개선이다. 전체 KLReq 준수 구현은 아니다.

참고한 절은 7.1.1(줄 나눔 선택), 7.1.2–3(글줄 시작/끝 금칙), 7.2.3.4(단락 정렬), 7.3.1(글자 간격), 7.4.1(줄 간격)이다. 참조 문서는 2026-03-21 Group Note Draft이며 인증 기준으로 취급하지 않는다.

## 적용 범위

- S04: Markdown 구문 트리에서 ATX 제목의 첫 HeaderMark에 속하는 뒤쪽 ASCII 공백·탭만 미리보기에서 숨긴다. 활성 줄·원문 모드는 원본을 보여준다. 들여쓰기와 내부/끝 공백, escape된 해시와 코드는 보존한다.
- S12: 한국어 본문과 제목, 노트 목록 및 연결 패널에 시작선 정렬, `word-break: keep-all`, `line-break: strict`를 적용한다. 어절 단위 유지(`keep-all`)는 가로쓰기 편집 경험을 위한 제품 선택이며 KLReq가 일률적으로 요구하는 유일한 방식이 아니다. 금칙 처리는 브라우저가 지원하는 범위에서 적용한다. 긴 단일 어절/URL에는 `overflow-wrap: anywhere`로 넘침을 방지한다. CodeMirror의 기존 줄바꿈 클래스보다 구체적인 선택자로 실제 편집기에 적용한다. 글꼴 다운로드나 문자열 수정은 없다. 제목의 음수 자간을 없애고 기존 비례 행간을 유지한다.
- S17: 그래프의 단일 grid 열을 버튼 폭까지 확장해 짧고 긴 제목의 시작선을 통일한다. 버튼 동작과 포커스 표시는 유지한다.
- 원문·활성/비활성 인라인 코드·들여쓴 코드·fenced 코드·수식/다이어그램에는 한국어 산문용 어절/금칙 정책을 적용하지 않는다. 기존 문법 표현과 스크롤/줄바꿈 동작을 유지한다.

## 검증

`tests/unit/editor.test.tsx`는 공백·탭·들여쓰기·닫는 해시·코드/escape 및 활성/비활성 전환과 원본 바이트를 확인한다. `tests/e2e/korean-layout.spec.ts`는 실제 Chromium의 제목 시작 위치와 길이가 다른 그래프 제목 시작 위치, 실제 적용된 CSS, 원문 복귀와 저장, 키보드 포커스, 없는 노트 생성 진입을 확인한다. 별도 좁은 화면 검사는 짧은 한글 어절과 분해형 자모/가족 이모지의 줄 분리 여부를 실제 텍스트 범위 좌표로 검사하며 120글자 무공백 문자열의 비상 줄바꿈도 확인한다. 활성 인라인·들여쓴 코드의 실제 스타일과 저장 바이트를 검사한다.

밝은/어두운 테마의 1440px·390px 화면은 `docs/screenshots/korean-layout-*.png`, 그래프 전용 캡처는 `docs/screenshots/korean-graph-*.png`에 보관한다. `tests/visual/korean-layout.spec.ts`는 고정 시각의 합성 노트로 데스크톱 제목·그래프와 좁은 그래프의 Chromatic 스냅샷을 만든다. 좁은 화면의 한글 문장과 괄호, 분해형 자모, 이모지 가족 문자열을 포함한다. 화면 확인은 모든 문장부호·글꼴·브라우저 조합이나 네이티브 IME 검증을 뜻하지 않는다. 브라우저의 Unicode 줄바꿈과 글꼴 shaping에 의존하며 세로쓰기·출판용 양끝 맞춤·전각 부호 간격의 별도 조정은 구현하지 않았다.

검증 실행: Node.js 24.18.0 / Yarn 4.18.1. 통합 단위 104개, 타입 검사, `/granite/` 빌드 통과. 최초 통합 브라우저 67개와 시각 캡처 8개 통과 후 코드 예외 보완 및 두 브라우저 회귀를 추가했으며, 최종 단위 104개·타입·빌드와 관련 브라우저 8개를 다시 확인했다. 빌드는 기존 대형 청크 안내를 출력했다. 이 기록은 로컬 검증이며 원격 CI/Chromatic 승인이나 실제 폴더 선택창 검증을 의미하지 않는다.
