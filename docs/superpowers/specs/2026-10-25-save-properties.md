# 저장 시 정리와 직접 속성 값 입력

2026-10-25 사용자 방향 변경: Chromatic 상태는 사용자 확인용이므로 별도 보고하지 않는다. 수동 문서 정리 버튼 대신 입력 중단과 Cmd/Ctrl+S에서 자연스럽게 정리한다. 속성 선택 후 값을 넣는 과정이 불편하다는 구체적 피드백을 반영한다. 모든 구현/검증/리뷰는 Sol6.1, main 직접반영 합의 유지.

## S20 저장 시 정리

기존1500ms idle/defaulton 설정은 유지한다. Cmd/Ctrl+S는 브라우저 저장창을 막고 현재 문서의 로컬 포매터를 확인창 없이 실행한 다음 정상 workspace 저장 경로로 저장한다. 자동정리 설정off이면 정리 없이 저장한다. 수동 문서정리 버튼은 상단툴바에서 제거한다. 내부 플러그인/수동미리보기 API는 호환을 위해 유지할 수 있으나 기본작업흐름으로 노출하지 않는다.

호출 시 문서/저장소/리비전을 고정하고 오래된 비동기결과는 적용하지 않는다. 조합입력·선택·완성/붙여넣기 메뉴로 안전하게 정리할 수 없으면 원문 저장을 우선하고 기존 idle재개계약을 따른다. 정리실패는 원문저장을 막지 않는다. 빠른반복CmdS는 중복처리/오래된문서저장 없이 안전해야 한다. 저장상태는 실제flush완료에 따라 갱신한다. 자동포매팅/저장은history별도단위와 undo재정리억제·focus유지·CRLF/frontmatter보호를 유지한다. 보통autosave650ms를 막거나 무한format/save순환을 만들지 않는다.

## S21 직접 값 편집

속성 이름을 고르면 같은 패널의 작은 값 입력칸으로 초점이 이동한다. YAML의 빈문자열로 점프하지 않는다. 입력을 Enter/추가로 확정하고 Escape로 취소한다. 값 입력 중 Cmd/Ctrl+S는 유효한 값을 먼저 확정한 뒤 저장하며, 잘못된 값은 초안과 오류를 유지한다. 확정 전에는 비어있는 속성을 문서에 미리쓰지 않는다. 기존 문자열·숫자·불리언/null scalar값은 해당행에서 수정할 수 있다. 값유형에 적합한 컨트롤/검증을 제공하고 알수없는 타입도 일반문자열로 입력가능하다. 배열/맵·여러줄복합값은 임의flatten하지 말고 원문편집으로 연결한다.

YAML 원문은 접을 수 있는 보조영역으로 유지하며 기존완성기능을 유지한다. 사용자가직접원하면 펼쳐수정할 수 있다. 새속성/값변경은정확한텍스트patch로 주석/순서/unknown키/줄바꿈을보존한다. 외부/동시본문변경으로 편집시점이 낡았으면 덮어쓰지말고 초안/오류를보존한다. 문서전환시속성입력초안이다른노트에적용되지않는다. 키/값입력의조합/선택/포커스/긴한글/좁은폭·다크모드 검증.

## 검증

CmdS실제키입력→확인창없음→정리저장→재열기, 실패원문저장, off설정, 지연중편집/노트변경/반복저장, 조합/메뉴/선택보호, undo. 속성검색→값입력→Enter/Escape, 기존값수정/타입오류, 주석CRLF/복잡한YAML보존, 오래된초안거절, 노트전환, 그래프갱신/저장재열기. 운영컴포넌트Storybook을 갱신하고작은캡처를직접검토한다. 전체단위/타입/앱·Storybook빌드/E2E/컴포넌트/시각검사와독립리뷰 후 mainpush/Pages확인. Chromatic검사는내부적으로유지하되승인대기를최종보고하지않는다.

## S23 속성 값에서 기존 노트 연결

2026-10-25 도그푸딩 피드백은 **명세 보완**이다. author/about처럼 문자열 값을 입력하는 곳에서도 본문처럼 기존 노트를 검색해 연결할 수 있어야 한다.

- 새 속성과 기존 단일 문자열 값의 초안에서 `@검색어` 또는 `[[검색어`를 입력하면 현재 로컬 저장소의 기존 노트 제목을 검색한다. 이메일 중간의 @는 열지 않는다. 없는 결과는 분명히 안내하며 직접 입력/확정할 수 있다. 새 노트 생성이나 날짜 명령은 제공하지 않는다. 검색 후 최대20개를 보여주며 더 구체적인 검색어로 다른 노트도 찾을 수 있다.
- 선택은 기존 escape 규칙의 일반 `[[제목]]` 문자열을 삽입한다. @는 입력 메뉴 진입점일 뿐 저장 문법이 아니다. 트리거 앞뒤 텍스트를 보존하고 이미 있는 닫는 `]]`는 중복하지 않으며 삽입 뒤로 커서를 옮긴다.
- 방향키로 후보를 고르고 Enter로 선택한다. 긴 목록에서도 선택한 후보가 목록 안에 보이도록 목록만 스크롤하고 문서 스크롤과 입력 초점은 유지한다. 선택은 속성 확정과 구별하며 다음 Enter가 값을 확정한다. Escape는 메뉴부터 닫고 다음 Escape가 초안을 취소한다. 마우스로 골라도 입력 초점을 유지한다. Cmd/Ctrl+S는 강조된 후보를 암묵적으로 고르지 않고 현재 문자 그대로 유효한 초안을 확정/저장한다.
- 조합 입력은 후보 선택/확정/취소가 가로채지 않는다. 커서/선택 범위·문서/저장소·원문이 바뀌면 오래된 후보는 적용하지 않는다. 값 입력 중 컨트롤을 다시 만들지 않아 초점과 선택을 보존한다.
- 기존 숫자·불리언·null은 노트 완성을 제공하지 않고 기존 타입/오류/초안 보호를 유지한다. 배열·맵·여러 줄 값도 기존 YAML 원문 흐름을 유지한다. 노트·속성·연결은 같은 로컬 Markdown patch/저장 경로를 사용하며 원격 업로드를 추가하지 않는다.
