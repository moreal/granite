# S30 CMS의 글쓰기 경험

2026-10-30 사용자의 블로그 CMS 경험 이식 요청은 **방향 변경**이다. 질문 없이 구현·검증하는 위임에 따라 기존 Solid/CodeMirror와 S01–S29의 저장·초안·링크 계약 위에서 구현한다. 참고 소스는 moreal/blog 커밋 bce1def86351f6c57f73991c2eb6d1d54feefb25의 src/admin/ui이며 실제 화면은 읽기 전용으로 확인했다.

- **S30a 글쓰기 면:** 기본 화면은 양쪽 탐색을 접고 명시적인 열기 작업을 제공한다. 검색·최근·데일리·덤프·새 노트·저장소·설정과 연결 그래프는 그대로 접근한다. 노트 정체성은 작은 상단 제목으로, 속성은 접히는 밴드로 둔다. 본문은 독립 스크롤하고 데스크톱19.2px/1.6,41em(787.2px) 폭, 위48px·좌우24px·아래40vh 여백을 쓴다. 320/390px의 좁은 창에서도19.2px/1.6과24px 좌우 여백을 유지한다. 기존 기본 탐색 표시·700px/17px 고딕 본문 요구를 이 기준이 대체한다.
- **S30b 서체와 테마:** 정확한 Noto Serif KR을 출처·OFL과 함께 자체 제공한다. Google Fonts 등 제삼자 요청을 만들지 않는다. UI와 코드는 기존 전용 서체를 유지하고 밝게/어둡게 토큰과 대비를 유지한다.
- **S30c 읽으며 고치기:** ATX/Setext 제목, 강조·인라인 코드·인용의 Markdown 표시는 희미한 원문으로 남긴다. 제목 계층은 CMS의1.6/1.35/1.15em을 따른다. 링크·이미지는 기존 선택 접촉 시 원문 규칙, fence 정보 숨김·수식·Mermaid·CAS 이미지·원문 보기·@/[[·붙여넣기·자동 정리는 유지한다.
- **S30d 목차:** 실제 본문에서1–3단계 ATX/Setext 제목을 읽고 두 개 이상이면 목차를 제공한다. 코드·메타데이터의 가짜 제목은 제외한다. 커서의 현재 구간을 표시하고 선택하면 해당 제목 끝으로 커서를 옮겨48px 여백으로 스크롤하고 편집기로 초점을 돌린다. 넓은 편집 영역1300px 이상에서는 제목,641–1299px에서는 펼칠 수 있는 막대,640px 이하는 숨긴다. 목차가 입력 글을 가리거나 문서·undo를 다시 만들지 않는다.
- **S30e 집중과 보호:** 본문 입력 시 주변 작업은0.2로 약화하고 포인터 복원120ms·키보드 즉시 복원·reduced motion을 유지한다. hover/초점과 열린 속성은 선명하다. 저장 상태·오류·충돌·복구와 메뉴는 절대 약화하지 않는다. 탐색·속성 토글은 편집기 정체성·커서·조합·undo·미확정 속성 초안을 보존한다. 자동 저장과 외부 변경 충돌 보호는 그대로다.

선택한 접근은 기존 편집기에 CMS의 표현·배치를 이식하는 것이다. CSS만 흉내내면 스크롤·목차·편집 피드백이 빠지고, CMS 전체를 복사하면 로컬 자동 저장·평면 노트·안전 계약을 잃으므로 채택하지 않는다. 발행·서버 저장·강제 덮어쓰기·계층 파일명·인증·미리보기 서버는 범위 밖이다. 합성 예제로 회귀와 좁은/넓은 밝게/어둡게 화면을 검증하며 실제 폴더 picker·권한창·OS IME와 구분한다.
