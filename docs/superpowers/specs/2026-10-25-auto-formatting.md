# S20 자동 문서 정리

2026-10-25 사용자가 수동 hongdown 실행을 자동으로 바꾸는 방향을 승인했다. 기본 활성화, 설정에서 비활성화한다. 기존 플러그인/원문 보호/저장 계약을 유지한다.

- 기존/새 설정에서 autoFormat 기본값 true. 명시적 false는 유지하고 테마·링크 양식을 보존한다. 설정 적용/취소/탭 동기화에 기존 계약을 사용한다.
- 실제 사용자 본문 입력·삭제·붙여넣기 후 1500ms 조용한 시간이 지나면 로컬 hongdown을 실행한다. 열기·프로퍼티 동기화·원문 보기 전환·설정 켜기만으로는 정리하지 않는다.
- 한글 조합, 비어 있지 않은 선택, 완성/붙여넣기 메뉴, 수동 정리 확인 중은 대기한다. 해제 후 자격 있는 편집이 남아 있으면 새 1500ms 대기를 시작한다. 메뉴/대화상자 포커스를 빼앗지 않는다.
- 편집 재개·문서/저장소 변경·잠금·설정 끄기·unmount는 타이머와 실행 중 결과를 취소한다. 실행 중 커서/선택이 바뀐 경우 이전 커서를 복원하지 않는다. 키/리비전/원문/선택/조합 상태를 적용 전에 다시 검증한다.
- 자동 정리는 확인 대화상자 없이 한 undo 단위로 적용한다. 초점·스크롤을 강제로 이동하지 않는다. 실행 취소/다시 실행 자체는 새 자동 정리를 예약하지 않는다. 정리 결과를 undo한 즉시 재적용하지 않고 다음 실제 본문 편집까지 기다린다. 정리 자체로 무한 재예약하지 않는다.
- 실패/시간초과/내용보존 검사 거절은 원문과 일반 자동 저장을 유지한다. 자동 정리 오류는 작은 비차단 상태로 표시하고 다음 실제 편집 전에는 무한 재시도하지 않는다. 새 사용자 편집은 오류를 지운다. 저장 완료를 포매팅 완료와 혼동하지 않는다.
- 수동 문서 정리의 미리보기/취소/적용은 유지하며 자동 작업과 동시에 실행하지 않는다. 기존 CRLF/frontmatter/위키/이미지/수식/Mermaid 보호와 참조 링크를 유지한다.

검증: 기본값/false/기존설정 마이그레이션/설정탭동기화, 실제 WASM으로 편집 후 자동적용/저장/새로고침, 단순열기 비변경, 연속입력 debounce, 조합/선택/메뉴 대기 및 해제, 늦은결과 취소(입력·노트전환·커서·설정off), undo유지/redo/수동공존, 실패시 정상저장, 라이트/다크 좁은설정화면. 합성 조합 검증은 네이티브 IME와 구분한다.
