# 글에 이미지·수식·코드·다이어그램 담기

2026-10-24 개밥먹기 피드백. 이미지와 풍부한 본문 표시는 명세 확장, 새 노트로 옮기기 제거는 방향 변경이다. 사용자의 기존 질문 없이 진행 요청에 따라 아래 세부 사항은 구현 기본값으로 선택했다.

## S05 제거

선택 내용을 새 노트로 옮기는 버튼·대화상자·실행 경로를 제거한다. 일반 새 노트 생성, 선택·복사·붙여넣기, 기존 노트·링크·초안은 유지한다. 이전 데이터는 수정하지 않는다. S05 번호는 폐기 이력으로 남긴다.

## S13 로컬 이미지

- 이미지 파일이 포함된 붙여넣기를 받아 원본 바이트 SHA-256으로 저장한다. PNG/JPEG/GIF/WebP는 바이트 서명으로 판별하며 SVG·알 수 없는 형식과 20MiB 초과 파일은 오류를 알리고 원문을 보존한다.
- 실제 폴더의 `assets/<sha256>.<확장자>`에 원본을 저장하고 `![이미지](assets/...)` 같은 일반 상대 Markdown 링크를 넣는다. assets는 내부 첨부 디렉터리이며 노트 목록은 기존 평면 구조를 유지한다. 동일 바이트는 재사용하고 이미 있는 파일의 내용이 다르면 덮어쓰지 않는다.
- 데모 이미지는 별도 IndexedDB에 저장한다. 원격 업로드·동기화·이미지 변환·자동 삭제는 없다. undo 또는 취소 뒤 남은 미참조 첨부는 보존한다.
- 첨부 쓰기가 완료되기 전에 본문을 바꾸지 않는다. 실패하면 선택된 글을 포함한 기존 본문이 유지된다. 대기 중 다른 위치의 입력은 삽입 위치에 반영하고, 대기 선택 영역 수정·노트/저장소 전환·잠금은 오래된 삽입을 취소한다.
- 미리보기는 허용된 로컬 첨부 경로만 읽고 object URL을 수명에 맞게 폐기한다. 누락·변조·권한 오류는 본문을 잃지 않는 상태로 보여준다.

## S14 편집 가능한 표현

- 기존 한 화면 편집을 유지한다. 원문 모드에서는 모든 문법이 그대로 보인다. 라이브 미리보기에서 이미지·수식·Mermaid는 선택이 구문에 닿으면 원문이 보이고, 벗어나면 렌더링한다. 렌더링을 클릭해서 원문으로 돌아갈 수 있다.
- 코드 fence의 언어에 맞는 구문 색상을 적용한다. 알 수 없는 언어는 평문 코드로 남으며 코드 안의 수식·Mermaid 문법을 중복 해석하지 않는다.
- 수식은 KaTeX로 `$…$` 인라인과 별도 줄 `$$`로 둘러싼 블록을 지원한다. 인라인은 한 줄이며 안쪽 공백·escape·통화처럼 보이는 숫자 경계와 코드/링크 구문을 구분한다. TeX 원문은 저장 그대로 유지한다. KaTeX 미지원 명령은 원문과 오류로 복구 가능하다. 임의 HTML·URL·전역 매크로 공유는 허용하지 않는다.
- Mermaid는 `mermaid` fence만 렌더링한다. 사용자 config·외부 리소스·스크립트 실행을 허용하지 않고 잘못된 다이어그램은 원문을 유지한다. 라이브러리·수식 폰트는 앱 자산에서 제공한다.
- 비동기 렌더링은 오래된 노트나 파괴된 위젯을 갱신하지 않는다. 저장·오류·초안 표시와 조합 입력의 안정성을 유지하고 좁은 화면에서 본문 밖으로 넘치지 않게 한다.

## 검증

해시 중복·변조·형식/크기·쓰기 실패·읽기 격리, 붙여넣기 지연 중 입력/전환, 이미지 재열기, 수식/코드/Mermaid 정상·오류·unsafe 입력, 원문 모드·클릭 편집·좁은 화면을 검증한다. 합성 clipboard 이벤트와 디스크 handle 대역은 OS 클립보드·폴더 선택창·네이티브 IME 검증으로 주장하지 않는다. 에이전트 구현과 독립 리뷰 후 기존 Yarn 검사와 Playwright 회귀를 실행한다.
