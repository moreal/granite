# 간결한 글쓰기 화면과 맥락별 링크 편집

사용자 피드백: 현재 화면이 지나치게 산뜻하다. 간결함과 가독성을 높이고 blog.moreal.dev CMS의 집중·링크 편집 방식을 참고한다. 기존 기능·저장 계약은 유지한다.

## 참고 확인

참고 커밋: `bce1def86351f6c57f73991c2eb6d1d54feefb25`. 라이브 화면이 아닌 실제 소스를 조사했다.

- `livePreview.ts:102–106,201–219`: 선택 범위가 링크 구문 전체와 맞닿거나 교차할 때만 해당 링크의 원문을 드러낸다. 같은 줄의 다른 위치는 조건이 아니다. 레이블은 버튼이 아닌 편집 가능한 텍스트 장식이다.
- `Editor.tsx:74–101`, `admin.css:662–685`: 입력 중 헤더·메타데이터를 흐리게 하고 마우스 이동 시 복원한다.
- `Outline.tsx`, `admin.css:805–865`: 제목 개요가 현재 구간을 따라가며 창 폭에 따라 간소화된다.
- 본문 폭·서체는 고정값이며 타자기식 커서 중앙 고정이나 서체 설정 메뉴는 확인되지 않았다.

## 이번 변경의 수용 기준

1. **맥락 링크:** 원문 보기에서는 전체 Markdown을 유지한다. 라이브 프리뷰에서는 Markdown 링크와 `[[노트]]`의 레이블을 보여준다. 커서 또는 선택이 해당 구문의 범위에 닿을 때(양끝 포함) 그 링크만 원문으로 바뀐다. 같은 줄의 다른 링크는 계속 프리뷰 상태다.
2. **편집과 이동:** 보이는 레이블을 일반 클릭하면 편집 위치를 잡고 원문을 드러낸다. Cmd/Ctrl+클릭은 내부 노트 또는 안전한 HTTP(S) 외부 링크를 연다. 사용 방법은 한 곳에 간단히 표시한다. 링크 밖으로 커서를 옮기면 프리뷰로 돌아간다. 링크 미리보기 hover만으로 내용이 바뀌지 않는다.
3. **안전:** 여러 줄 링크는 안전한 원문 폴백을 유지한다. 코드 안 링크는 편집·탐색 대상으로 취급하지 않는다. 한글 조합 중 장식을 불필요하게 다시 만들지 않는다. 문서 바이트와 붙여넣기·취소·자동완성 동작은 보존한다.
4. **간결한 시각 체계:** 크림색·초록색 배경과 식물 장식·홍보 문구·장식 카드·대형 명조 제목을 제거한다. 무채색 배경, 짙은 본문, 보조 글자, 구분선, 절제된 링크 색의 기존 CSS 토큰으로 통일한다. 새로운 스타일 프레임워크·서체 다운로드는 도입하지 않는다.
5. **가독성:** 본문 17px, 행간 약 1.8, 제목 약 28px 고딕체. 제목·본문·하단 작업 영역의 최대 폭은 700px로 통일한다. 좁은 화면에서도 본문 16px 이상을 유지한다. 저장·오류·탐색 텍스트 대비는 4.5:1 이상을 유지한다. 상태를 감추기 위해 저대비 흐림을 적용하지 않는다.
6. **집중 모드:** 탐색·연결 패널을 숨기는 기존 집중 모드는 유지한다. 실제 표시 상태와 버튼 이름·아이콘·aria 상태가 일치해야 한다. 집중 모드에서 연결 패널 열기를 누르면 집중 모드를 종료하고 패널을 보여준다. 기본 화면에서 탐색을 갑자기 숨기지 않는다.
7. **기능 보존:** 시작 화면은 간결한 제목·설명·폴더 열기·데모 진입으로 정리한다. 데일리·덤프·검색·옮기기·백링크·재발견·복구와 에러 안내는 유지한다. 재발견은 단순한 노트 항목으로 보여주며 글쓰기보다 강조하지 않는다.

## 범위와 검증

CMS의 자동 흐림과 개요 전체를 이번 변경에 새로 도입하지 않는다. 이번 목적은 기존 화면의 단순화와 정확한 링크 맥락 편집이며, 저장·복구 코드를 재설계하지 않는다.

회귀 테스트: 같은 줄의 둘 이상 링크, 링크 내부/경계/외부 커서, 레이블 클릭 후 편집, Cmd/Ctrl 클릭 이동, 여러 줄·코드·한글 문서 보존, 집중 중 연결 패널 열기. 기존 단위·E2E·타입·빌드 검사 및 실제 데스크톱·좁은 창 시각 확인을 수행한다.
