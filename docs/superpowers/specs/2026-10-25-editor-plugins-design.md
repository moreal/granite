# 편집기 플러그인과 Markdown 표현

2026-10-25 도그푸딩: frontmatter 중복 노출과 인용문 누락은 명세 보완(S04/S17), hongdown과 플러그인 구조는 범위 확장(S20). 사용자는 질문 없이 구현·검증을 위임했고 main 직접 반영을 승인했다. 라이선스는 사용자 요청에 따라 AGPL-3.0-or-later로 전환한다.

## 의도와 선택

쓰는 화면은 본문에 집중하고 메타데이터는 속성에서 다룬다. 원문과 저장 안전성은 유지한다. blog.moreal.dev CMS의 hongdown은 화면 렌더러가 아닌 저장 시 포매터다. CodeMirror를 유지하며 표현 확장, 입력 명령, 문서 포매터를 별도 플러그인으로 등록한다. 전면 편집기 교체는 기존 입력·복구 계약을 불필요하게 바꾸므로 선택하지 않았다. 임의 외부 JS를 설치하는 마켓플레이스 대신 앱에 포함한 TypeScript 플러그인을 조합한다.

## S04/S17 표현과 보존

- 유효하고 닫힌 맨 앞 YAML은 라이브 본문에서 중복 표시하지 않는다. 속성 패널과 원문 보기로 편집할 수 있다. 잘못되거나 닫히지 않은 YAML은 경고와 원문을 유지한다. 본문의 ---는 속성으로 숨기지 않는다.
- 한 개의 전체 Markdown 문서를 유지한다. 초기 커서는 본문 시작으로 놓고 선택이 메타데이터에 들어오면 원문을 드러낸다. 숨겨진 속성을 지우려는 첫 입력은 삭제 대신 원문을 드러낸다. select-all은 원문을 드러낸 뒤 작동한다. 프로퍼티 동기화 및 undo/redo는 정당한 변경을 보존한다. CRLF와 빈/메타데이터만 있는 파일을 다룬다.
- 인용문은 차분한 왼쪽 선과 들여쓰기로 표시한다. 비활성 줄의 >와 구분 공백을 숨기고 활성 줄/원문에서는 정확히 드러낸다. 중첩·연속 문단·빈 인용 줄·lazy continuation을 지원한다. escape 및 코드의 >는 인용문으로 처리하지 않는다.
- 모든 표현은 전체 저장 문자열을 변환하지 않는다. frontmatter 영역에는 본문 링크·수식·이미지 장식을 적용하지 않는다. 기존 한국어 줄바꿈·밝기/어둡기·좁은 창·조합 입력 보호를 유지한다.

## S20 플러그인과 hongdown

- 안정된 ID를 가진 타입화한 플러그인 목록에서 live CodeMirror 확장, @/[[ completion provider, 문서 formatter를 등록한다. 중복 ID는 명확히 거절한다. 예제 테스트 플러그인은 Editor 내부 분기 수정 없이 새 포매팅과 @ 명령을 추가할 수 있어야 한다.
- 호스트가 현재 문서/리비전/잠금/IME/취소/dispatch를 소유한다. 플러그인은 저장소 객체나 자동 네트워크 권한을 받지 않는다. 내장 플러그인은 신뢰된 앱 코드이며 보안 샌드박스라는 주장은 하지 않는다.
- 기존 날짜·노트 검색을 provider로 옮긴다. @는 입력 메뉴일 뿐이고 날짜는 실행 순간 계산한다. 이메일·코드·frontmatter에서는 메뉴가 뜨지 않는다. [[ 새 연결과 링크 escape 계약을 유지한다.
- hongdown의 실제 고정 버전 WASM을 로컬 worker로 실행한다. 노트 업로드나 외부 formatter command 실행은 없다. 실행은 명시적 문서 정리 명령으로 제공하고 적용 전 원문/결과를 확인하고 취소할 수 있다. 적용은 한 undo 단위이며 정상 저장/충돌/복구 경로를 따른다.
- 대기 중 편집·노트 전환·잠금·조합 입력 또는 다른 포매팅 요청은 오래된 적용을 거절한다. 변경되지 않은 결과는 불필요한 저장을 만들지 않는다. 오류/로드 실패는 원문을 보존하고 설명한다.
- 유효 frontmatter 원문은 분리해 그대로 보존한다. 부정확한 frontmatter는 포매팅을 거절한다. 위키링크·로컬 첨부 경로·수식·Mermaid 의미가 바뀌는 결과는 적용하지 않는다. hongdown의 reference link 출력은 편집/이동 가능해야 한다. 문서 정리의 스타일 변화는 미리보기에서 보인다.
- AGPL 라이선스·홍다운의 GPL 고지와 정확한 대응 소스/빌드 방법을 배포물에서 접근 가능하게 제공한다.

## 검증

S04/S06/S07/S10/S13/S14/S17/S20: frontmatter 표시·경계 삭제·원문·속성·undo/redo·재열기, 인용문 중첩/코드/escape, 등록 예제, 날짜 실행 시점, stale async formatter, 홍다운 실제 브라우저 worker, reference links, 이미지/수식/Mermaid 보존, HTML 비실행, 라이트/다크 데스크톱/390px. 단위·타입·빌드·전체 E2E·시각 테스트와 독립 리뷰를 수행한다. 네이티브 IME/권한 UI는 합성 테스트와 구분한다.

### S20 실행 한계와 검토 방식

초기 배포는 전체 UTF-8 입력 1 MiB 이하, worker 10초 제한을 둔다. 원문과 결과는 실행되지 않는 읽기 전용 텍스트로 나란히 표시하고 좁은 화면에서는 위아래로 표시한다. Hongdown 0.5.3의 줄 폭 재배치, Setext H1/H2, 스마트 문장부호를 끄고 backtick fence 3개 및 math를 사용한다. 이미지 구문 변경은 경로 해석 위험을 줄이기 위해 보수적으로 거절할 수 있다. 이 보호는 모든 미지원 Markdown 문법의 의미 동등성 보장을 뜻하지 않는다. 사용자가 결과를 검토하고 적용한다.
