# S28 속성 노트 링크의 직접 이동과 미리보기

2026-10-26 사용자 피드백은 두 부분이다. 실제 운영 속성 링크는 이미 S26의 초안 보호를 거쳐 바로 노트를 연다. Storybook만 합성 대상·돌아가기·작업 결과 문구를 남겨 중간 단계처럼 오해하게 했다(**검토 예제의 명세 위반**). hover/키보드 초점 미리보기는 **명세 보완**이다. 기존 S04 본문 링크의 편집·Cmd/Ctrl 이동 규칙은 바꾸지 않는다.

- **S28a 직접 이동:** 읽는 속성의 링크는 일반 클릭/Enter/터치 첫 조작으로 기존 앱의 노트 열기 경로에 전달한다. 미리보기 안의 추가 열기 버튼·확인 단계·작업 결과 live region은 없다. 미확정 속성 값이 있으면 S26/S25의 적용/취소 안내·값/오류·입력 초점 보호를 유지한다. 없는 대상은 클릭할 때만 기존 생성 확인을 연다.
- **S28b 미리보기:** mouse/pen hover 약200ms 또는 키보드 초점 즉시 제목과2–4줄의 짧은 내용을 보여 준다. 미리보기를 열기 위해 초점을 강제로 옮기지 않으며 터치 클릭만으로 미리보기를 열지 않는다. 링크와 미리보기 사이를 건너 읽거나 텍스트를 선택할 수 있고 포인터가 떠나면 닫는다. Escape는 미리보기만 닫고 초점을 유지하며 다시 진입/초점을 받기 전까지 열리지 않는다. 미리보기는 비모달·비대화형이며 탭 순서·레이아웃·속성 후보/작업 버튼 위치를 바꾸지 않는다.
- **S28c 로컬 안전과 수명:** 현재 메모리에 있는 노트/초안에서만 제목과 최대240자의 일반 텍스트를 얻는다. 기존 frontmatter 파서로 닫힌 메타데이터만 제외하고 닫히지 않은 원문은 안전한 텍스트로 남긴다. HTML 실행·외부 가져오기·저장/생성/스키마 변환은 없다. 빈 노트와 없는 노트를 구분한다. 대상 내용/문서/잠금 변경, 스크롤·크기 변경·언마운트에서 오래된 미리보기/타이머/전역 이벤트를 정리한다.
- **S28d 화면과 예제:** S27 토큰을 쓰는 최대약320px 읽기 표면을 뷰포트 안에12px 여백으로 배치하고 좁은 창·라이트/다크에서 확인한다. 동작 애니메이션이나 초점 이동을 추가하지 않는다. PropertiesLinks play는 실제 속성 화면과 미리보기에서 끝내며 합성 대상 화면/오해되는 작업 결과를 남기지 않는다. 클릭 예제는 현실적인 노트 내용으로 곧바로 이동한다. 운영 story와 실제 앱의 hover/키보드/Escape/클릭·없는 대상·초안 보호를 회귀로 확인한다.

범위는 읽는 속성 링크다. 본문 편집기 링크, 전체 원문/YAML, 원격 미리보기·새 저장 기능은 포함하지 않는다. 합성 Chromium/데모 증거와 실제 폴더 picker/권한·OS IME·스크린리더 확인은 구분한다.
