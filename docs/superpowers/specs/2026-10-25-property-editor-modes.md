# S24 속성 편집 방식 실험과 유형 안내

2026-10-25 사용자 결정: 속성 폼과 YAML 편집기를 모두 제공하고, 설정에서 하나를 선택한다. 기본값은 폼이다. 두 방식을 동시에 표시하던 기존 S21의 보조 YAML 편집기는 제거한다. 정렬은 S12/S22 위반 수정이고, 두 방식 선택과 유형 안내는 S21/S23에서 빠진 요구 및 방향 변경이다.

- **S24a 한 번에 한 방식:** 설정 > 글쓰기의 실험 항목에서 폼/YAML을 선택하고 이 브라우저에 저장한다. 오래된/잘못된 설정은 폼으로 연다. 바꾸기만 해서는 노트에 쓰지 않는다. 전체 Markdown 원문을 보고 있으면 속성 패널은 읽기 안내만 표시한다. 복잡하거나 잘못된 속성은 폼에서 전체 원문으로 연다. 돌아오면 선택한 방식으로 돌아온다.
- **S24b 초안 보존:** 적용 전 속성 값 초안이 있으면 방식 변경을 보류하고 적용/취소 안내를 표시한다. 처음 속성을 만들기 전의 유형 검색 문자는 방식/원문 전환 후에도 보관하고, 폼으로 돌아오면 이어서 입력한다. 기본 Thing만 있는 새 노트는 방식 변경을 지연하지 않는다. 숫자 입력 오류, 다른 탭의 설정 변경, 원문으로 이동한 경우에도 값은 보관한다. 문서나 원문이 달라진 초안은 덮어쓰지 않고 기존 오류/취소 흐름을 유지한다. 전환 때문에 몰래 적용하지 않는다.
- **S24c 같은 완성 규칙:** 폼의 기존/새 type 및 @type에는 Schema.org 유형을 추천한다. 속성 이름 추천은 유지한다. 폼 문자열과 YAML 및 전체 원문 속성 값은 @/[[로 기존 노트를 검색하고 일반 [[제목]] 링크를 넣는다. YAML에서는 한 줄 최상위 문자열과 직접 블록 목록의 문자열 항목을 지원한다. 별칭/사용자 태그/주석/블록 문자열/중첩 맵/흐름 목록/본문에서는 완성하지 않는다. 인용하지 않은 [[입력은 첫 위키 트리거에 한정하며, 쉼표·중괄호·추가 대괄호처럼 흐름 목록과 구별할 수 없는 문자는 완성하지 않는다. 이런 제목은 YAML 따옴표 안에서 제한 없이 검색할 수 있다. 관련 없는 문법 오류가 있거나32,768자를 넘으면 완성하지 않는다. 처리할 수 없는 원문도 그대로 저장하고 편집할 수 있다.
- **S24d 원문과 키보드:** 첫 줄의 `type:`처럼 완성 중인 YAML이 일시적으로 잘못되어도 같은 입력창·초점·선택 범위와 native 입력 이력을 유지한다. 원문이 같은 저장/검증 갱신은 입력창 값을 다시 대입하지 않고, 실제 다른 원문/문서 변경은 반영한다. YAML 오류 안내는 입력창 아래에 표시하여 나타나거나 사라져도 입력 위치가 움직이지 않는다. 선택한 scalar 토큰만 필요한 YAML 인용/위키 이스케이프로 교체한다. 나머지 주석·인용·CRLF·본문은 유지한다. 방향키/Enter/Escape/Tab·선택 범위·문서/커서 변경·disabled/readOnly·조합 입력은 기존 보호를 유지한다. Cmd/Ctrl+S는 강조 후보를 선택하지 않는다. Chromium의 입력/CodeMirror 완성은 한 번 실행 취소한다. 다른 엔진의 textarea 대체 입력은 안전한 텍스트 교체를 제공하지만 native undo를 보장하지 않는다. 후보 이동은 목록만 스크롤한다.
- **S24e 부드러운 유형 안내:** 현재 로컬 작업공간의 최신 노트에서 선언 유형을 읽는다. schema.org URL/여러 유형/상속을 정규화하고 속성 rangeIncludes의 여러 유형을 대안으로 취급한다. author는 Person 또는 Organization, about은 Thing으로 Book 등 하위 유형을 허용한다. 일치 후보, 미지정/알 수 없는 유형, 확인된 불일치 순서로 보여 주되 검색되는 기존 노트를 제외하지 않는다. 폼/YAML 목록은 순위 계산 후 처음20개를 표시하고 검색어를 좁히는 안내를 제공한다. 검색 범위는 전체 노트이며 뒤쪽의 불일치 후보도 제목을 좁히면 찾을 수 있다. 전체 원문 목록도 한 번에20개만 렌더링한다. 후보에는 실제 유형과 기대 유형을 보이고 알려진 불일치 연결에는 저장 가능한 안내를 표시한다. 사용자 정의 유형·속성/미해결 링크는 불일치로 단정하지 않는다. 대상 유형 변경은 추천/안내에 반영한다. 저장을 차단하거나 유형을 자동 변경하지 않는다.
- **S24f 실제 정렬:** 속성 이름과 첫 값 줄을 정렬하고40px 클릭 영역을 유지한다. 읽기/입력/열린 후보를 실제 운영 컴포넌트의 데스크톱/320px 라이트·다크에서 확인한다.

런타임 어휘는 이미 고정된 오프라인 Schema.org30.1 카탈로그이다. [데이터 모델](https://schema.org/docs/datamodel.html), [기대 유형 안내](https://schema.org/docs/gs.html), [rangeIncludes](https://schema.org/rangeIncludes)의 상속과 대안 범위 의미를 따른다. 노트 읽기/쓰기와 자동 저장은 기존 로컬 workspace 경로 하나를 사용하며 원격 조회/업로드나 데이터 이관은 없다. S01/S04/S10/S17의 저장·복구·연결 보장을 유지한다.
