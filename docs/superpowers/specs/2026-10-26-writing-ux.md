# S29 연결 미리보기와 간결한 속성·설정

2026-10-26 피드백의 본문/그래프 미리보기와 간결한 속성 입력·세로 설정 분류는 **명세 보완**이며, 수동 문서 정리 검토 UI 폐기는 **방향 변경**이다. 기존 데이터와 S01–S28 보호를 유지한다.

- **S29a 공통 미리보기:** 속성·본문의 렌더링된 내부 `[[링크]]`·노트 그래프에서 같은 S28 미리보기 제어기를 쓴다. 200ms hover/즉시 키보드 초점, 좁은8px 연결 영역 유지·영역 밖120ms 닫기, Escape·로컬240자 평문·수명 정리를 유지한다. 본문 일반 클릭은 S04 편집, Cmd/Ctrl+클릭은 이동이다. 비활성 렌더링 링크를 Tab으로 초점받게 하되 선택/커서/원문을 바꾸지 않는다. 해당 DOM 링크의 Enter만 이동하며 편집기 본문의 Enter는 계속 입력한다. 그래프의 일반 클릭/Enter/터치 첫 조작은 바로 기존 이동 경로로 전달한다. 외부 링크·YAML·전체 원문에 내부 미리보기를 넣지 않는다.
- **S29b 작은 속성 행과 이어 쓰기:** 읽는 속성과 type 행·분리된 편집 버튼·추가 작업은32px 기본 리듬을 쓴다. 활성 값 입력과 적용/취소는 기존40px를 유지해 후보/작업의 안정된 위치와 읽기 크기를 보존한다. 평상시에는 별도의 영구 검색/추가 폼 없이 `+ 속성 추가`만 보인다. 누르면 같은 영역에서 이름을 입력하고 기존 유형별 추천·사용자 정의 이름을 쓴다. 후보 선택/Enter/Tab은 값 입력으로 이어지고 값 Enter/적용으로 확정한다. blur로 미완성 값을 저장하지 않는다. 취소/적용 후 추가 버튼으로 초점을 돌린다. 다른 행/추가/링크 요청은 S25의 단일 초안·오류·입력 초점을 보존한다. 숫자·범위 안내·@/[[ 완성·YAML 실험 설정·잘못된 원문 복구는 유지한다.
- **S29c 자동 정리:** 수동 정리 검토 대화상자와 Components/Format 예제를 제거한다. S20 자동 정리의 idle/CmdS 자동 정리, 설정·undo·실패 원문 저장/복구·stale 요청 방지는 유지한다. 제거로 기존 노트나 초안을 변환하지 않는다.
- **S29d 설정 왼쪽 분류:** 설정 분류를 왼쪽 세로 내비게이션, 선택 내용을 오른쪽에 둔다. 좁은320/390px에서도 세로 분류를 유지하고 텍스트를 줄바꿈한다. 네이티브 버튼/키보드·현재 분류 표시·임시 설정·취소/적용·다른 탭 충돌 계약과 접근 가능한 footer를 유지한다.

회귀는 실제 앱의 본문 초점/선택 보존·Enter/일반 클릭·수정키 이동, 그래프 직접 이동·미리보기, 이름→값→확정과 미완성 초안 보호, 좁은 세로 설정을 확인한다. 운영 Storybook의 작은 라이트/다크·좁은 화면과 관련 전체 검사로 확인하며 데모/Chromium 결과를 실제 폴더 picker·권한·OS IME·스크린리더 결과로 주장하지 않는다.

S29a는 S28의 속성 전용 범위 제한을 확장한다. S29b는 S24f의 기본40px 중 읽는 속성 행만32px로 바꾸며, 초기 유형 전용 생성 폼 대신 일반 속성 추가로 type을 입력한다. S29c는 S20의 수동 검토 유지 요구를 폐기한다.
