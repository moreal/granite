## S17 schema.org 기반 노트 그래프

참고: https://wiki.g15e.com/pages/Wiki%20gardening%20rules 와 https://schema.org/ . 참조 위키의 optional type/평면 저장/없는 페이지 링크를 따른다. 속성 이름을 관계로 표시하는 것은 Granite의 설계 선택이다.

각 노트는 파일명으로 구분되는 그래프 노드다. 제목/name 속성으로 파일을 암묵적으로 변경하지 않는다. 앞부분 YAML frontmatter의 optional `type` 또는 `@type`을 읽고 Book/Person/Article/ScholarlyArticle/CreativeWork 등의 schema.org 타입과 사용자 타입을 보존한다. 타입이 없으면 일반 노트로 남으며 자동 메타데이터 삽입은 하지 않는다.

frontmatter는 기존 Note.body의 원문으로 유지한다. 주석·미지정 속성·공백을 자동 재직렬화하지 않으며, 사용자가 속성을 편집할 때만 해당 범위가 바뀐다. YAML 오류·과도한 크기/깊이·alias/custom tag 등 지원하지 않는 입력은 원문을 유지하고 오류를 보여준다. 메타데이터 값은 HTML로 실행하지 않는다.

본문 `[[링크]]`와 frontmatter의 직접 문자열/문자열 배열 `[[링크]]`를 그래프로 표현한다. 속성 관계는 author/about 등 입력된 이름을 표시한다. frontmatter 링크를 본문 링크로 중복 계산하지 않는다. 없는 노트도 관계 대상으로 보여주며 기존 생성 흐름으로 연결한다. 타입 추론·역관계 합성·외부 schema 요청은 하지 않는다.

속성은 접을 수 있는 작은 편집 영역에서 원문 YAML로 고친다. 현재 노트의 들어오는/나가는 관계를 제목·타입·속성 이름으로 탐색한다. 이번 범위는 전체 공간을 움직이는 그래프 캔버스가 아니라 정확한 그래프 모델과 현재 노트의 연결 탐색이다. 미저장 초안 변경도 관계에 반영하고 저장·복구 안전 계약을 유지한다.
