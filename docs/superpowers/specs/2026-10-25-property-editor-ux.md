# S25 차분한 속성 입력과 초안 보존

2026-10-25 실제 운영 폼/YAML의 전문가 평가와 사용자 피드백을 반영한다. 경고 시점·행 이동 시 초안·포커스·문구는 S21/S24의 빠진 요구이며, 보이지 않는 키보드 후보와 잘못된 YAML의 폼 생성은 S12/S22/S24a 위반이다. 기존 두 방식 설정과 정확한 원문 자동 저장은 유지한다.

- **S25a 조용한 YAML 입력:** YAML과 전체 원문에서 입력·조합을 시작하면 이전 속성 경고를 감춘다. 입력창에 머물러 생각하는 동안 타이머로 경고하지 않는다. 편집 영역을 떠나거나 Cmd/Ctrl+S를 누르면 남아 있는 경고를 차분한 안내로 드러낸다. 후보 선택은 편집의 일부다. 처음 열린 잘못된 문서는 경고를 표시하며 수정하면 즉시 사라진다. 문법·형태·유형 안내는 저장 실패와 구분하고 실제 저장/충돌 오류는 즉시 유지한다. 동일 textarea·초점·커서·native 이력과 입력창 위쪽 위치는 S24d대로 유지한다.
- **S25b 발견과 복구:** 검증되었거나 처음 열린 잘못된 속성은 접힌 요약에도 작은 `확인 필요` 표시를 제공한다. 읽지 못한 유형에 기본 Thing을 확정된 유형처럼 표시하지 않는다. 자세한 YAML 안내는 입력 아래에 두고 드러난 오류만 aria-invalid/설명과 연결한다. 원문은 정확히 자동 저장되며, 고친 뒤 속성과 연결에 반영됨을 설명한다.
- **S25c 검색 결과:** 지원하는 YAML 기존 노트 검색이 0개이면 간결한 결과 없음 안내를 제공한다. 지원하지 않는 문맥과 구분하고 가짜 후보/빈 링크를 넣지 않는다. 유형 검색의 결과 없음은 유형을 가리키며 사용자 정의 유형 입력을 허용한다. S24c/d의 조합·범위·오래된 후보 보호를 유지한다.
- **S25d 하나의 폼 초안:** 기존/새 속성 또는 같은 행을 선택해도 미확정 초안과 오류를 초기화하지 않는다. 먼저 적용/취소하도록 안내하고 현재 초점으로 돌아간다. 숫자 검증 실패와 방식/원문 변경의 초안도 보존하며 몰래 확정하지 않는다. 읽을 수 없는 YAML로 바뀐 경우에도 이전 초안·오류·취소를 유지한다.
- **S25e 키보드 연속성:** 초기 유형과 속성 이름의 방향키 이동은 활성 후보를 팝업 안에 보이게 하며 입력 초점과 문서 스크롤을 유지한다. 기존 속성 적용/취소는 그 값 버튼, 새 속성 적용/취소는 속성 이름 입력으로 초점을 돌린다. 보류된 YAML 전환은 YAML 입력으로 이어지며 문서/원문이 바뀌면 제거된 폼 요소로 초점을 보내지 않는다.
- **S25f 정직한 폼:** 안전하게 읽은 최상위 맵이 없으면 새 속성 검색/추가를 제공하지 않고 보관 안내와 기존 전체 원문 수정 동작을 제공한다. 유형 값 안내나 편집 가능한 알 수 없는 키를 구문 실패로 오인하지 않는다. 자동 정규화·삭제·설정 변경은 하지 않는다.

S01/S04/S10/S17/S21/S23/S24의 로컬 저장·복구·링크·정확한 패치 계약을 유지한다. 폴더 선택/권한창이나 운영체제 IME 검증을 데모/합성 이벤트 검사로 대신했다고 주장하지 않는다.
