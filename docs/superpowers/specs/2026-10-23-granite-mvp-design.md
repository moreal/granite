# Granite MVP 스펙 초안

상태: 구현 기준 초안. 2026-10-23 사용자가 추가 질문 없이 구현·검증까지 위임했다. 아래 기본값은 도그푸딩으로 수정한다.

## 목적과 합의

개인 오픈소스 지식 관리 도구. 데스크톱 Chrome에서 로컬 폴더를 열고 평문 Markdown으로 기록한다. 화면에는 디렉터리 개념이 없다. 사용자는 자연어 스펙·디자인·사용 경험에 집중하고, 구현과 준수 검증은 별도 에이전트에 맡긴다.

주요 흐름: 데일리 또는 덤프 노트에 생각·자료·출처를 모은다 → 일부 내용을 선택해 새 노트로 옮긴다 → 원래 자리에 링크가 남는다 → 새 노트가 열리고 이어서 다듬는다 → 링크·백링크·검색·재발견으로 생각을 연결한다.

## MVP 수용 기준

- **S01 시작/저장:** 시작 화면에서 로컬 폴더를 선택한다. 권한을 얻은 폴더 최상위의 `.md`를 읽고 쓴다. 하위 디렉터리는 탐색하지 않는다. 사용자 데이터는 서버로 보내지 않는다. 데모는 별도 브라우저 저장소를 사용하며 명확히 표시한다. 데모 데이터는 실제 폴더에 복사하지 않는다.
- **S02 노트:** 제목과 Markdown 본문으로 이루어진 노트를 생성·편집·자동 저장한다. 제목·본문 검색, 최근 노트 목록, 오늘의 노트와 덤프 바로가기를 제공한다. 같은 저장소를 다시 열면 마지막으로 열어 둔 노트(새로 만들거나 옮겨서 열린 노트 포함)를 이어서 연다. 기억한 노트가 없거나 사라졌으면 기존 노트를 안전하게 열고, 빈 저장소는 빈 상태로 시작한다. 빈 제목·동일 제목 생성은 기존 파일을 덮어쓰지 않고 안내한다. 최초 생성 후 제목 변경과 삭제는 MVP 범위 밖이다.
- **S03 파일명:** 정상 길이 제목은 URL percent-encoding 기반 `.md` 파일명으로 저장한다. `/`, `?`, `:`, `%`, 이모지와 한글을 지원한다. 경로 구분자로 해석하지 않는다. 인코딩 후 긴 제목은 짧은 결정적 해시 파일명을 사용하고 정확한 제목을 Markdown의 메타데이터에 보존한다. 대소문자 충돌, Unicode 정규화, 예약 파일명, 해시 충돌을 감지해 기존 노트를 덮어쓰지 않는다. 파일명 인코딩과 링크 표시는 분리한다.
- **S04 편집:** 참고 CMS의 라이브 프리뷰를 따른다. 제목·강조·인라인 코드·Markdown 링크·위키링크를 읽기 좋게 표시하고 편집 중인 부분은 원문으로 수정 가능하다. 링크는 선택이 전체 구문의 범위에 닿을 때 해당 링크만 원문을 드러내고, 레이블 일반 클릭은 편집·Cmd/Ctrl+클릭은 이동에 사용한다. 원문 보기 전환을 제공한다. 한글 조합 중 명령 메뉴가 입력을 가로채지 않는다. 사용자 HTML은 실행하지 않는다.
- **S05 옮기기:** 본문 범위를 선택하고 ‘새 노트로 옮기기’를 실행해 제목을 입력한다. 선택한 텍스트를 새 노트 본문으로 저장한 뒤 원문 범위를 `[[제목]]` 링크로 교체·저장하고 새 노트를 연다. 대상 제목 중복·저장 실패 시 원문을 유지한다. 두 파일을 단일 원자 작업으로 저장했다고 주장하지 않는다. 대상 저장 후 원본 저장 실패 시 원문은 보존하고 생성된 사본 존재를 알리며 원본 편집을 유지한다. 처리 중 추가 실행·원문 변경을 막는다.
- **S06 연결:** `[[`로 제목 검색 자동완성을 연다. 방향키·Enter·Escape와 마우스로 선택한다. 선택한 기존 노트 링크 또는 없는 제목의 링크를 삽입한다. 없는 노트 링크를 열면 생성할 수 있다. 제목에 대괄호나 역슬래시가 있는 경우 일관되게 escape/unescape한다. 코드 블록·인라인 코드 안의 예시는 실제 연결로 취급하지 않는다.
- **S07 @ 메뉴:** `@`는 슬래시 커맨드와 같은 입력 메뉴 진입점이며 저장 문법이나 예약어가 아니다. 오늘·어제·내일 명령과 기존 노트 검색을 제공한다. 날짜 명령은 실행 시점의 로컬 날짜를 `YYYY-MM-DD`로 계산해 일반 `[[날짜]]` 링크를 삽입한다. 시간 경과에 따라 링크가 바뀌지 않는다. 이메일 중간의 `@`는 메뉴를 열지 않는다.
- **S08 외부 출처:** HTTP(S) URL 붙여넣기 시 URL 그대로 / 별칭 달기 / 제목 가져오기를 제공한다. 선택 텍스트가 있으면 별칭으로 쓴다. 계속 입력하거나 Escape를 누르면 URL을 보존하며 메뉴가 닫힌다. 제목 가져오기는 진행·실패 상태를 제공하고 응답 대기 중 변경된 텍스트를 덮어쓰지 않는다. 서버 없는 MVP에서는 CORS가 허용되는 URL만 직접 가져올 수 있다. 실패하면 원래 URL을 유지하며 수동 별칭을 사용할 수 있다. 인증·우회 프록시·외부 서비스는 도입하지 않는다.
- **S09 발견:** 현재 노트로 향하는 백링크와 주변 문맥을 보여준다. 클릭해 원본 노트로 돌아갈 수 있다. ‘다시 발견’은 현재 노트를 제외한 다른 노트를 제시한다. 작성 중 자동 팝업으로 방해하지 않으며 패널을 접어 집중할 수 있다. 빈 저장소·한 개 노트도 정상 동작한다.
- **S10 데이터 보호:** 저장 완료 표시는 디스크 또는 데모 저장 성공 이후에만 한다. 미저장·저장 중·실패를 구분한다. 노트 이동 시 미저장 내용을 잃지 않는다. 권한 거부·재연결·쓰기 실패를 복구 가능한 메시지로 다룬다. 마지막으로 읽은 파일과 외부 수정이 충돌하면 자동 덮어쓰기를 거부하고 편집 초안을 유지한다. 브라우저 새로고침 이후에도 실패한 초안을 복구할 수 있게 저장소별로 분리해 보관한다.
- **S11 리뷰:** 샘플 노트가 있는 데모 모드, 재현 가능한 Playwright E2E, 단위 테스트, 프로덕션 빌드, 한국어 리뷰 가이드를 제공한다. 폴더 선택창은 자동화의 제약을 명시하며 가능한 어댑터 경계 테스트와 실제 디스크 smoke test로 보완한다. 검증하지 않은 네이티브 권한 UI를 검증했다고 주장하지 않는다. 모든 PR에서 단위·타입·빌드 및 Chromium 브라우저·디스크 검사를 자동 실행하고 실패를 체크 실패로 표시한다. 생성된 Playwright HTML 보고서와 성공·실패 trace는 14일 보관한다. 설치와 개발·검증 명령은 정확한 버전이 고정된 Yarn을 사용하고 `nodeLinker: pnpm`으로 `node_modules`를 구성한다. `yarn.lock`을 커밋하고 로컬 재현·CI는 `yarn install --immutable`로 잠금 파일 변경을 거부한다.
- **S12 사용성:** 한국어 UI, 키보드 접근 가능한 버튼·대화상자·메뉴, 명확한 저장 상태, 읽기 편한 여백·서체와 차분한 시각적 계층을 갖춘다. 좁은 창에서도 필수 작업이 가려지지 않는다. 리뷰 화면은 구현 설명보다 실제 노트와 글쓰기 경험에 집중한다.

## 구조와 범위

React + TypeScript + Vite, CodeMirror 6 편집기. 저장 어댑터는 실제 File System Access API와 데모 localStorage를 분리하고 같은 노트 작업을 사용한다. 노트 검색과 백링크는 로컬에서 계산한다. Vitest와 Playwright를 사용한다. Storybook은 필수가 아니며 실제 동작하는 데모와 E2E 보고서로 리뷰를 지원한다.

후속 범위: 모바일·Safari/Firefox의 실제 폴더 편집, 동기화·협업·계정, AI 추천, PDF/이미지 첨부 관리, 제목 변경/삭제, 완전한 Markdown 확장 호환성, 자동 외부 링크 상태 검사, 무제한 크기 저장소. 일반 사용자 파일은 무단 변환하지 않는다.

## 검증과 후속 개발

각 수용 기준은 테스트 또는 수동 검증 절차에 연결한다. 도그푸딩 이슈는 ‘스펙 위반 / 스펙 부족 / 방향 변경’으로 나누고, 뒤의 두 경우 스펙부터 수정한다. 독립 검토자가 데이터 손실·주요 흐름 누락을 확인한다.
