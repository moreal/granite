# 설정, 링크 붙여넣기, 테마

사용자 피드백 2026-10-25. main에 직접 반영한다. Chromatic Build 2의 여섯 변경 승인은 로그인 대기 중이며 사용자는 구현을 먼저 진행하도록 선택했다. 승인 여부를 구현 완료와 혼동하지 않는다.

## S08 링크 붙여넣기 확장

CMS 참조 커밋 bce1def86351f6c57f73991c2eb6d1d54feefb25의 src/admin/ui/linkPasteActions.ts·linkPasteMenu.ts를 조사했다. 참조는 URL 그대로/별칭/제목 가져오기 액션과 서버측 제목 정리 규칙을 제공한다. 사용자 Markdown 템플릿 설정 UI는 없으므로 아래 템플릿은 Granite 확장이다.

HTTP(S) 단일 URL을 붙이면 URL을 먼저 넣고 커서 근처 메뉴를 연다. 선택 텍스트가 있으면 별칭으로 활용한다. 별칭 선택 시 선택 텍스트가 없으면 `[](URL)`의 대괄호 안에서 바로 입력한다. 화살표/Enter/Escape 및 마우스로 선택하며 IME 조합을 방해하지 않는다. 문서/선택 변화·다른 노트/저장소·잠금·메뉴 닫힘 뒤 오래된 비동기 결과가 글을 바꾸지 않는다. 이미지 붙여넣기는 기존 우선순위와 안전 계약을 유지한다.

설정에서 이름과 Markdown 템플릿을 추가·편집·삭제한다. `{{url}}`, `{{title}}`, `{{selection}}`, `{{hostname}}`를 지원하고 URL 자리표시는 필수다. 미지원/잘못된 자리표시와 지나치게 큰 입력은 저장 전에 설명한다. 미리보기는 가상 값을 사용하는 텍스트이며 네트워크/코드 실행이 없다. 대체되는 외부 제목·선택 문장은 일반 텍스트와 링크 레이블에 삽입하기 위한 Markdown escape를 적용한다. 코드 문자열이나 YAML 등 임의의 중첩 언어 문맥을 해석하는 범용 템플릿 엔진은 아니다. 템플릿의 Markdown 자체는 사용자가 정한 내용으로 보존한다.

`{{title}}`이 필요한 액션을 사용자가 선택했을 때만 제목을 가져온다. 브라우저 CORS 제약을 유지하고 외부 프록시/서버를 추가하지 않는다. 실패 시 이미 붙인 URL을 유지하고 오류를 알린다. 제목은 og:title 우선, title 폴백이며 공백·길이를 제한한다. 요청/응답 크기와 시간 제한을 둔다.

## S19 설정과 외관

설정은 앱 화면에서 접근하는 간결한 모달로 제공한다. 외관과 링크 붙여넣기 두 영역을 둔다. 라이트·다크·시스템 선택을 제공하며 기본은 시스템이다. 시스템 모드에서 OS 테마 변경을 즉시 반영하고 수동 모드는 그 영향을 받지 않는다. 같은 브라우저의 설정으로 저장하며 노트 파일에는 쓰지 않는다. 잘못된 저장값·저장 실패는 안전한 기본값/명확한 오류로 처리한다. 다른 탭의 설정 변경도 반영한다.

단순한 색상 토큰으로 본문·사이드바·모달·폼·오류·코드·KaTeX·Mermaid를 모두 대응한다. 첫 로딩의 테마 깜빡임을 최소화하고 전환이 글·선택·조합 입력을 잃게 하지 않는다. 저장 상태/오류 대비와 모션 줄이기 계약은 유지한다. 실제 라이트/다크와 좁은 화면으로 확인한다.

최근 노트는 제목만 표시하면서 데스크톱 행을 약32px로 줄인다. 제목 생략, 포커스 표시, 키보드 접근은 유지하며 coarse pointer에서는 44px 터치 영역을 확보한다. 검색 결과의 문맥 발췌는 유지한다.

## 검증

테마 선택·새로고침·시스템 변화·다른 탭 동기화·설정 취소/저장/오류, 템플릿 검증·미리보기·영속성, 붙여넣기 메뉴 키보드와 stale 응답·IME·이미지 우선순위, 라이트/다크 코드와 수식/다이어그램을 검증한다. UI 변경은 실제 화면과 Chromatic 업로드로 추적하되 인증되지 않은 승인을 주장하지 않는다.
