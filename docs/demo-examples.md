# 직접 고쳐 보는 데모 예시 (S15)

`직접 고쳐 보는 생각의 지도`는 이미지, 인라인·블록 수식, JavaScript·Python 코드, Mermaid를 한 편의 글에서 직접 편집하는 예시다. 클릭 편집과 원문 보기 안내를 포함한다. 로컬에서 직접 만든 720×240 PNG를 앱 자산으로 묶고 운영 `putImage`를 통해 SHA-256 경로와 데모 IndexedDB에 저장한다. 이미지 원격 요청이나 업로드는 없다.

기존 데모에도 버전별로 한 번 추가한다. 이미 같은 제목이 있으면 `(2)`부터 빈 제목을 고른다. 기존 노트·초안·마지막 선택은 바꾸지 않는다. 이미지 저장 후 생성 예정 제목을 pending 기록으로 남기고, 노트 생성 후 complete로 바꾼다. 완료 표식 쓰기 실패 뒤 재시도는 pending 파일의 내용을 그대로 보존하며 완료한다. pending 중 사용자가 동일 파일을 먼저 생성한 경우도 덮어쓰지 않고 해당 버전의 예시 추가를 끝낸다. 완료 뒤 예시 수정·삭제를 자동 복구하지 않는다.

지원 브라우저에서는 Web Locks로 두 탭의 시드를 직렬화한다. Web Locks가 없는 환경은 같은 탭의 중복 열기를 직렬화하며, 기존 저장소의 제목 충돌 검사로 덮어쓰기를 막는다. 이 fallback에 대해 탭 간 단일 실행을 보장하지 않는다.

## 검증

`tests/e2e/demo-examples.spec.ts`의 S15 검증은 새 데모, 기존 제목 충돌, 사용자 편집 후 재열기, 이미지 저장 실패 재시도, 완료 표식 실패 재시도, 두 탭 동시 열기, 실제 IndexedDB 이미지 재열기 및 동일 바이트 경로 재사용을 다룬다. 화면 검증은 데스크톱·760px 창의 이미지/수식/Mermaid 표시, 가로 넘침 없음과 수식 원문 수정 후 새로고침 보존을 확인한다.

이는 브라우저 데모 검증이며 OS 클립보드, 폴더 선택창, 실제 폴더 권한 또는 네이티브 IME 검증이 아니다.

2026-10-24 실행 결과: Node 24.18.0 / Yarn 4.18.1에서 단위 71개, 전체 브라우저·디스크 52개 통과(40.0초). 별도로 기존 정적 빌드 preview의 `/granite/` 경로에서 예시 이미지·수식·Mermaid, desktop/narrow 화면과 수식 편집·새로고침 보존을 실제 Chromium으로 확인했다(1개 smoke 통과). 위 네 화면을 열어 그림, 수식, 코드 색상, 다이어그램과 좁은 화면 줄바꿈을 확인했다. 이미지 저장 실패와 완료 표식 quota 실패는 의도적으로 주입한 실패이며 실제 디스크 부족을 일으킨 검증이 아니다.
