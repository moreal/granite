# 설정·테마·최근 노트 검증 (S19)

화면 설정은 시작 화면과 노트 탐색 영역의 설정 버튼에서 연다. 밝게·어둡게·시스템 선택과 사용자 링크 양식을 하나의 초안으로 편집하고 적용한다. 취소·Escape는 변경을 저장하지 않고 진입 버튼으로 초점을 돌린다. 입력칸·textarea를 포함한 대화상자 초점 순환을 유지한다.

설정은 `granite.settings.v1` 브라우저 저장소에만 기록한다. 노트 파일을 수정하지 않는다. 잘못된 버전·형태·양식은 기본값으로 복구하며 저장 공간 오류는 대화상자에 표시한다. 다른 탭에서 변경된 설정을 열린 대화상자가 덮어쓰려 하면 적용을 거부하고 다시 열도록 안내한다. 다른 탭의 적용은 열린 앱의 테마와 붙여넣기 양식에 반영한다.

테마는 편집기 인스턴스를 다시 만들지 않고 CSS 변수로 적용한다. 시스템 모드만 OS 변경을 따른다. Mermaid 테마는 별도 rich-preview 변경과 연동한다. 최근 노트는 데스크톱 32px 행·한 줄 말줄임으로 표시하고 coarse pointer에서는 44px 클릭 영역을 유지한다. 검색 결과의 기존 문맥은 보존한다. 애니메이션은 추가하지 않았다.

검증: Node.js 24.18.0, Yarn 4.18.1에서 설정 단위 테스트 3개와 브라우저 테스트 4개 통과. 브라우저에서는 설정 영속성·시스템 변경·사용자 양식 추가/취소·유효하지 않은 양식 편집을 확인했다. 외부 탭 충돌 회귀와 앱 모듈을 차단한 첫 화면 테마 테스트도 통과했다. 문서 head의 작은 bootstrap이 저장된 테마 또는 시스템 설정을 읽어 앱 로딩 전 배경과 색상 모드를 적용한다. 타입 검사 통과. `/tmp/granite-settings-dark-desktop.png`, `/tmp/granite-settings-dark-narrow.png`, `/tmp/granite-settings-light-narrow.png`를 실제 렌더링해 열어 보고 본문·설정·좁은 화면의 적용 버튼과 대비를 확인했다. 좁은 양식 대화상자는 내부 스크롤과 하단 적용 영역을 사용한다. OS 파일 선택·권한 흐름 검증을 주장하지 않는다.
