# 코드 언어와 최근 목록 간소화

2026-10-25. [글쓰기 집중 명세](superpowers/specs/2026-10-24-writing-focus.md)의 S02/S04/S12/S14 명세 보완이다.

최근 노트는 제목만 표시한다. 본문 검색 결과에는 일치 문맥을 살펴볼 수 있도록 기존 미리보기를 유지한다. 코드 블록은 Markdown 구문 트리의 `CodeInfo` 범위를 fence와 함께 숨기며, 여는 줄을 편집하거나 원문 보기로 전환하면 언어와 부가 정보를 다시 드러낸다. 원문이나 저장소를 변경하지 않는다.

검증: `tests/e2e/quiet-ui.spec.ts`에서 최근 목록의 정확한 접근 가능한 이름, 검색 미리보기, 백틱·물결표 fence의 언어/부가 정보 숨김과 복원, 코드 본문 및 저장 바이트 보존을 확인한다. Node.js 24.18.0과 Yarn 4.18.1에서 해당 E2E 2개가 통과했다(3.5초). 전체 회귀 및 실제 화면 확인은 통합 검증 기록에 추가한다. 이 데모 검증은 실제 폴더 선택·권한 흐름의 증거가 아니다.
