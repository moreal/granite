# 타입과 관계를 고치는 데모

S15/S17의 누락된 체험 예시를 보완한다. `src/storage/demo.ts`가 기존 데모 시딩 잠금 안에서 아래 가상 노트를 한 번만 추가한다. 모든 본문은 실제 인물·출판물이 아닌 연습용임을 명시한다.

| 노트                             | 타입    | 속성 관계                               |
| -------------------------------- | ------- | --------------------------------------- |
| 윤여울 — 가상의 작가             | Person  | 책·글의 author로 참조됨                 |
| 느린 질문의 숲 — 가상의 책       | Book    | author → 윤여울                         |
| 질문을 산책시키는 독서 — 예시 글 | Article | author → 윤여울, about → 느린 질문의 숲 |

속성과 노트 그래프를 펼쳐 author/about의 `[[제목]]`을 고치면 연결 대상이 즉시 바뀐다. 본문의 문법 예시는 인라인 코드로 표시해 의도하지 않은 본문 연결을 만들지 않는다. 저장 후 다시 열어도 편집을 유지한다.

`granite.demo.seed.typed-notes.v1`은 각 노트의 선택한 제목과 완료 상태를 보관한다. 의존 대상부터 생성하므로 제목 충돌 시 실제 접미사 제목으로 관계를 만든다. 생성 전에 pending을 기록하며, 생성 후 완료 기록이 실패해도 다음 실행에서 이미 존재하는 파일을 보존한다. 기존 글, 사용자가 고친 예시, 현재 선택, 초안을 바꾸지 않는다. 로컬 폴더에는 이 예시를 쓰지 않는다.

검증은 `tests/e2e/typed-demo-examples.spec.ts` 및 기존 `demo-examples.spec.ts`에 있다. 새 데모의 실제 Article/Person/Book 그래프, 관계 수정 직후 표시, 저장 후 선택·속성 복원, 제목 충돌, 일부 생성 후 완료 마커 실패 및 편집 보존, 두 탭 동시 열기를 확인한다. 데스크톱 그래프와 390px 속성 화면을 캡처한다. 좁은 화면 캡처에서 그래프는 화면 아래에 있으므로 좁은 화면 그래프의 시각 검증을 주장하지 않는다. 이 검증은 브라우저 데모 저장소 대상이며 폴더 선택기나 운영체제 권한 흐름 검증이 아니다.

검증 결과 (Node 24.18.0, Yarn 4.18.1): 집중 브라우저 검사 6개, 단위 검사 85개, 전체 E2E 58개, 시각 캡처 5개 통과. 타입 검사와 프로덕션 빌드도 통과했다. 시각 검사는 `/granite/` base 빌드를 사용했다. 일반 `/` 빌드로 실행한 첫 시각 검사는 경로 불일치로 중단했으며 올바른 base로 다시 빌드한 뒤 전체 통과했다. 원격 Chromatic 업로드는 실행하지 않았다.
