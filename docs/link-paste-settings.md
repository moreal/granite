# URL 붙여넣기와 사용자 링크 양식

2026-10-25. S08 확장·S19 설정의 구현 기록이다. CMS의 커서 근처 URL 메뉴와 별칭 편집 흐름을 참고했으며 사용자 정의 링크 양식 편집 화면은 Granite의 새 범위다.

- 공백 없는 단일 HTTP(S) URL은 먼저 원문으로 삽입한다. 커서 메뉴는 호스트 이름과 기본 세 선택, 저장한 양식을 표시한다. 위아래 화살표는 순환하며 Enter는 적용, Escape·외부 클릭·선택 이동·본문 편집은 닫는다. 메뉴 버튼으로 Tab 이동한 경우도 방향키·Enter·Space·Escape가 동작한다.
- 별칭 선택은 선택했던 글을 사용하거나 빈 `[]` 안에 커서를 둔다. 별도 입력 대화상자는 없다. 양식 적용은 하나의 편집이며 undo는 삽입했던 URL을 복원한다.
- 양식은 `{{url}}`, `{{title}}`, `{{selection}}`, `{{hostname}}`의 리터럴 치환이다. URL은 필수, 알 수 없거나 깨진 이중 중괄호는 오류다. 텍스트 값은 일반 본문·링크 라벨에 넣을 수 있도록 Markdown 구두점을 escape한다. 코드 span이나 HTML 속성 내부를 위한 문맥별 인코더가 아니며 양식 자체는 사용자가 작성하는 Markdown이다. 빈 선택은 빈 문자열이다. 실행·eval은 없다.
- 제목은 사용자가 제목 가져오기 또는 `{{title}}`이 있는 양식을 명시적으로 선택한 때만 요청한다. 브라우저 CORS, credentials omit, 12초 제한, 최대 1MiB 응답을 사용한다. OG 제목을 우선하고 HTML title로 대체하며 공백 정리 후 300자로 제한한다. 프록시·서버 업로드는 없다. 실패하면 URL을 그대로 두고 다른 방식을 고를 수 있다.
- 취소·이동·잠금·unmount는 요청을 중단하고 오래된 결과와 오류를 무시한다. 이미지 붙여넣기를 먼저 처리하는 기존 경로를 유지했다.
- 메뉴는 커서에 붙고 스크롤·창 크기 변경 때 위치를 다시 계산하며 화면 가장자리 8px 안에 제한한다. 활성 선택은 접근성 상태로 알린다.

## 검증

집중 단위 검증 19개 통과: 기존 이미지/링크 회귀, 선택 별칭, 키보드 순환, 빈 별칭 커서, IME 키 무시, 선택 이동, 취소 뒤 응답, OG 제목 및 escape, 템플릿 검증과 단일 치환. 초기 집중 브라우저 6개 통과: S08 기존 여정/취소, 설정 UI로 양식 추가 후 새로고침·키보드 선택·undo, 390px 메뉴 범위. 리뷰 수정 뒤 통합 결과는 최종 검증 기록을 따른다.

브라우저 붙여넣기는 합성 ClipboardEvent이고 제목은 네트워크 대역이다. OS 클립보드·실제 사이트 CORS·네이티브 IME·폴더 선택/권한 UI 검증을 주장하지 않는다.

통합 검증: 단위 99개, 타입 검사, `/granite/` Pages 빌드 통과. 기존 구문 색상 상수·메뉴 dialog 역할 기대 두 항목을 새 계약에 맞춰 수정한 뒤 최종 전체 E2E 66개가 54.2초에 통과했다. 시각 검증 기존 5개와 새 설정 2개, 총 7개 테스트·10개 명명 스냅샷이 통과했다. [밝은 메뉴](screenshots/link-menu-light-narrow.png)와 [어두운 메뉴](screenshots/link-menu-dark-narrow.png)는 390×700 실제 Chromium 화면을 열어 확인했다. 메뉴 버튼과 호스트가 잘리거나 화면 밖으로 넘치지 않았다.
